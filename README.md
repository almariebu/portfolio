# Almarie Bullo — Web Developer & ERP Developer

Personal portfolio for Frappe / ERPNext and web work. Live at [almariedev.com](https://almariedev.com/).

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Vercel

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Local development |
| `npm run build` | Production build |
| `npm run start` | Serve production build |
| `npm run lint` | ESLint |

## Customize

Edit `src/lib/content.ts` for copy, projects, tools, and contact links.

Panels are shareable via query string, e.g. `/?panel=work` or `/?panel=about`.

## Deploy

Connected to GitHub. Vercel deploys automatically from `main`.
